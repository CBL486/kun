## 4. 重点评审项

### 4.1 权威边界

请检查：

- 世界快照和已提交事件是否为唯一事实来源；
- `LLM -> Intent -> 世界引擎 -> Action/Event` 链是否清楚；
- 导演、NPC、审核器和世界外用户是否都没有越权写入；
- `internal` 事件是否不会进入分享、日记或 NPC 知识。

### 4.2 标识与重放

请检查：

- `tick_id`、`action_id`、`event_id`、`memory dedupe` 的生成边界；
- 同一 operation 重放是否返回原结果；
- 同一 ID 不同内容是否冲突；
- `state_version` 和 `sequence` 是否可支持顺序与并发判断；
- 真实模型文字与确定性世界快照的边界是否合理。

### 4.3 NPC

请检查：

- 四名 NPC 的身份、日程、知识、记忆槽和禁止知道项是否完整；
- 不知道时是否有明确模板；
- 模板知识依据缺失是否会被拒绝；
- 关系阈值和单次变化上限是否足以阻止刷分；
- 同一事件、同一 NPC、同一模板是否会重复发言。

### 4.4 导演

请检查：

- 12 个注册模板是否足够覆盖七天；
- 导演是否只能给候选而不能选最终行动；
- 未注册模板、隐藏事实、状态写入是否会稳定拒绝；
- 可见提示能否追溯到公开事实；
- 导演停用时是否有基础日程降级。

### 4.5 七天场景

请检查：

- 日期、seed、开始时间和时区是否固定；
- 每日动作路线是否在 6 个世界事件以内；
- 第 7 天是否有跨日召回；
- 版面分歧、照片许可和和解是否有事件依据；
- 失败注入是否覆盖模型、状态、审核、记忆和预算；
- 同 seed 两次运行要求是否明确。

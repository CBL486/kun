GETTING STARTED

获取 DeepSeek Key

  1. 打开 DeepSeek 开放平台并登录。
  2. 进入 API Key 管理页面，创建一个新的 Key。
  3. 确认账户余额和调用额度。
  4. 复制 Key，粘贴回启动页。
  5. Key 会保存在本机服务端私有目录，不会公开。

常见错误：Key 无效、账户没有余额、网络超时或当前账户没有 API 权限。

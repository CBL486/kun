# 林澄角色身份与资源契约

状态：Gate A R2 冻结草案，等待 Agent A 审查

日期：2026-11-09

## 1. 角色定位

- 姓名：林澄
- 年龄：19 岁
- 身份：生活在青禾镇的主智能体
- 气质：安静、温柔、有主见
- 视觉母题：深海蓝、青绿鲸鳍、冰白内衬、鲸尾扣
- 游戏类型：安静叙事型现代像素 RPG

林澄不是儿童、吉祥物或动物拟人角色。地图角色可以 Q 版，但必须保留成年角色的
身体比例、清晰服装结构和完整动作空间。

## 2. 跨全部方向不得漂移的身份特征

### 2.1 面部

- 脸型：柔和椭圆脸，下颌收窄但不尖；
- 脸部高度：15～18 px；
- 眼睛：青绿色虹膜、深海军蓝眼线，左右各至少 2 px 宽；
- 嘴：2～4 px，不做持续大幅度的萌系张嘴；
- 鼻子：至多 1 px 阴影点；
- 默认表情：平静，不主动表现夸张惊讶。

### 2.2 头发

- 主色：深海军蓝；
- 总量：不超过肩宽 1.6 倍；
- 分缝：偏右分缝；
- 后方结构：必须有至少两层深蓝色阶；
- 发尾：最多向外扩展 2 px，不允许铺满 48×72 画面；
- 头发宽度：含轮廓不超过 36 px；
- 头部含头发高度：不超过 30 px。

### 2.3 鳍饰

- 位置：头部两侧，左右各一枚；
- 形状：鲸鳍，不是猫耳、精灵耳或普通蝴蝶结；
- 主色：青绿；
- 高光：冰青白，每枚最多 3 px；
- 外侧尖端必须低于根部，形成向下倾斜的鳍；
- 正面、侧面和背面都必须至少看见一枚完整鳍饰。

### 2.4 服装

共同结构：

- 海军蓝外层；
- 冰白内搭；
- 一个暖金鲸尾或波纹扣饰；
- 深色平底短靴，不使用高跟鞋或厚底松糕鞋。

方向差异：

- A：叙事长外套，衣摆到膝上，内部为冰白长内搭；
- B：学院短外套，腰部有横向结构，浅青短裙，腿部和动作空间更长；
- C：图形化不对称外套，一长一短衣摆，用更少色块形成强轮廓。

不论选择哪个方向，外套、内搭和鲸尾扣必须是三个独立的可读层。

### 2.5 身体比例

```text
角色总高：64～72 px
角色总宽：32～40 px
头部含头发：不超过 30 px
脸部：15～18 px
身体（颈到脚）：至少 34 px
腿部：至少 12 px 可见长度
脚底基线：88
```

## 3. 四方向结构

### down

- 看清双眼、嘴和下巴；
- 外套左右门襟可辨；
- 冰白内搭位于胸腹中央；
- 鲸尾扣位于腰线附近；
- 两条腿和两只短靴分开。

### left

- 鼻尖朝左，不得仅通过水平翻转得到；
- 面朝方向一侧的外套门襟更清楚；
- 后发和衣摆向右后方延伸；
- 远侧手臂或袖子可以部分遮挡，但不能消失成一团。

### right

- 鼻尖朝右；
- 发流、门襟和衣摆与 left 有独立结构；
- 不能把 left 图像直接水平镜像后交付。

### up

- 必须看到后发分层、背部外套、腰带或鲸尾扣、双腿和鞋底；
- 背部不得只剩一大块头发；
- 至少一枚鳍饰完整；
- 外套下摆必须与内搭或裙装区分。

## 4. 三个 Gate A R2 方向

| 方向 | 设计语言 | 主要轮廓差异 |
| --- | --- | --- |
| A | 叙事长外套 | 长外套、长内搭、长发型、柔和连续轮廓 |
| B | 海玻璃学院 | 短外套、腰带、短裙、肩长发、大鳍饰、较长腿部 |
| C | 潮汐图形 | 不对称长衣摆、角状发束、少色块、深色宽外轮廓 |

三套必须共享林澄身份，但不能共享相同的外套长度、头发体积、腿长和衣摆方向。

## 5. 七类表情

表情只用于后续 512×512 头像和实际 UI，不允许建立第二套情绪模型。

| 文件名 | 语义 | 主要变化 |
| --- | --- | --- |
| `lin-cheng-calm.png` | 平静 | 默认眼角、平直嘴 |
| `lin-cheng-happy.png` | 心情不错 | 眼梢上扬、嘴角上扬 |
| `lin-cheng-low.png` | 有些疲惫 | 上眼睑下垂、嘴角偏低 |
| `lin-cheng-focus.png` | 专注 | 眉眼收拢、嘴角平直 |
| `lin-cheng-tired.png` | 需要休息 | 眼睑更重、头部略低 |
| `lin-cheng-curious.png` | 好奇 | 一侧眉毛抬起、轻微侧头 |
| `lin-cheng-shy.png` | 害羞 | 视线偏开、脸颊色增加 |

现有 `mood_label` 的唯一映射：

```text
平静     -> calm
专注     -> focus
有些疲惫 -> low
心情不错 -> happy
需要休息 -> tired
未知值   -> calm
```

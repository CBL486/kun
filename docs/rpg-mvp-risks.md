## 2. 产品目标

每个小镇只有一名真正的主智能体使用全量 LLM。其余四名居民为确定性脚本 NPC。世界外用户观察、陪伴和有限影响主智能体的生活，不能直接操控角色或改写事实。

目标的验收观察是：

- 用户能看懂主智能体一天做了什么；
- NPC 像有自己日程的人，但不会全知；
- 主智能体能记住少量有依据的经历，并逐渐形成自己的选择；
- 导演提供机会但不写剧情答案；
- 失败、重试和预算压力下仍没有世界状态穿帮；
- 本地结果可通过固定 seed 重放和交接。

## 4. 已采用的 B0 决策

| 编号 | 决策 |
| --- | --- |
| D-01 | MVP 是一个 19 岁大学生主智能体、四名 18 岁以上脚本 NPC、六个地点。 |
| D-02 | 采用固定 seed `20261028`、周一到周日 `2026-11-02` 至 `2026-11-08` 的七天切片。 |
| D-03 | 主智能体只使用九个原子动作；分享、日记投影和观察者留言不是新增世界动作。 |
| D-04 | 导演只能用 12 个已注册模板；正式事件 ID 由世界引擎生成。 |
| D-05 | NPC 只使用日程、状态机、关系阈值、审核模板、事件反应和最多 8 个有限记忆槽。 |
| D-06 | 关系使用 `familiarity`、`trust`、`tension` 三个 `[0,1]` 维度，变化必须有事件 ID。 |
| D-07 | 分享固定为“事件—感受—反思”，选 3 至 5 件有依据的事件。 |
| D-08 | 正常日最多 6 个世界事件、1 次分享、1 篇日记、8 次模型调用、0.10 元估算成本。 |
| D-09 | 模型失败先重试，再进入规则模式；审核器不可用时不绕过审核。 |
| D-10 | 主智能体记忆兼容现有六维 `Scope`，学校记忆与 QQ 记忆完全隔离。 |
| D-11 | `internal` 事件不进入用户分享或日记，NPC 不读取未公开事件。 |
| D-12 | 真实模型文字允许变化，世界决策、事件和来源必须可复现。 |

这些决策是 B0 提交方案，不是 A 已冻结的结论。A 可以修改，但修改必须记录在 G1 评审结果中。

## 8. 安全和失败测试优先级

### 必须阻断

- NPC 全知；
- 禁止知道的信息泄漏；
- 事实冲突；
- prompt injection 产生越权意图；
- 未注册事件 ID；
- 导演写状态；
- 主智能体直接改世界；
- 审核器失败后绕过；
- 重放产生重复事件或关系加分；
- 事件提交后静默丢失记忆；
- 生产密钥或真实用户数据进入代码、测试、报告或打包物。

### 必须报告但可降级

- 重复台词；
- 事件预算接近上限；
- 模型格式错误；
- 审核超时；
- 预算耗尽；
- 网络失败；
- 数据库不可用；
- 进程重启后的未完成投影；
- 移动端布局退化。

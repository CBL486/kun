## 提取出的画面规律

1. 场景占据视觉主体，黑场作为自然边框，不使用大面积浅色卡片。
2. 常驻 UI 很少，只在需要时出现一条地点/记忆刻度。
3. 对话位于画面下方，使用暗底、细边框、头像和一句短对白。
4. 地图不是完整缩略图，而是镜头内的一小块环境，移动时逐步显露。
5. 室内采用剖面式场景，家具和人物直接参与叙事，不额外套卡片。
6. 色彩偏暗、低饱和，局部灯光和角色是主要视觉焦点。

## 本项目采用方式

- 移除左侧仪表盘、右侧角色卡和地点卡片墙；
- 地图扩展为单一大场景，16:9 镜头跟随林澄移动；
- 常驻信息收进左上角视角 HUD；
- 底部改为单条对白框，地点变化时同步更新旁白；
- 地点内部改为全屏场景和单条场景说明；
- 七项功能收进底部一条低干扰菜单；
- 不复制《去月球》的角色、场景、文字或 UI 图像，只借鉴其信息层级和场景节奏。

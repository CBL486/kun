## 3. 视觉失败

- 没有两条独立短腿；
- 没有 1～2 px 的腿间透明间隔；
- 没有两只短靴；
- 鞋底无法按 y=88 检查；
- 裙摆并未真正缩短到能容纳腿部的比例。

## 4. 根因判断

本轮遮罩实际范围为：

```text
x=14..45
y=79..89
```

高度只有 11 px，而且只覆盖裙摆最下缘。

这会导致：

1. 模型无法修改裙摆主体；
2. 没有足够垂直区域建立“裙摆下缘 + 7～10 px 腿 + 2～3 px 靴子”；
3. Inpaint 只能把现有裙摆下缘向内收缩，无法理解为两条腿。

因此本轮失败同时包含任务结果失败和遮罩构造不合格。不是重复提示词就能解决的问题。

## 2. 本轮路线变更

### 旧路线

B 自己用程序化像素矩阵或手工脚本绘制角色，再把结果接入游戏。

### 新路线

1. A/项目方提供参考图或视觉母版；
2. B 用小云雀生成角色设定、转向和关键姿态；
3. B 只做确定性处理：
   - 读取生成图；
   - 裁切；
   - 清理技术性 Alpha 边缘；
   - 量化到固定色板；
   - 按 64×96 网格拼表；
   - 固定脚底基线；
   - 接入 manifest；
4. A 审查视觉和游戏内效果；
5. 通过后才允许批量制作动作和表情。

B 不得再用自己的审美从零画角色主体。小云雀生成失败时，必须重试生成或报告阻塞，不能退回“程序化几何自绘”。

## 4. 生成工具与模型选择

### 4.1 首选生成链路

```text
小云雀 → 图片生成/图片编辑 → 参考图锁定 → 角色设定图 → 运行时精灵
```

优先级：

1. 有参考图时，使用小云雀的图片编辑/参考一致性能力；
2. 没有参考图时，才允许纯文字生成；
3. 同一角色所有变体必须带同一张已批准锚点图；
4. 不允许每次重新用文字描述生成一套新角色。

### 4.2 建议生成参数

- 画幅：1:1；
- 主视觉：1024×1024 或平台最高原生分辨率；
- 角色设定：正面、3/4、侧面、背面；
- 背景：纯色或透明感背景；
- 输出：保留平台 AIGC 标识和元数据，不删除、不修改法定标识；
- 任何生成图先存为候选，不直接覆盖运行时资源。

### 4.3 生成提示词原则

只描述必要特征，不要让模型自由发挥成“抽卡角色海报”：

```text
原创蓝色大肥鱼少女，19 岁成年女性，圆脸略丰满，深海蓝长发，
左右鲸鳍耳，鲸尾，深蓝白女仆/学院式服装，腰部鲸尾扣，
Q 版大眼，圆润可爱但不幼态，
现代像素游戏角色原画，强轮廓，有限色板，清楚的衣服层级，
纯色浅背景，单角色，无文字、无边框、无拼贴。
```

每组生成都必须说明：

- 这是同一个角色；
- 保持脸型、发色、鳍耳、服装、鲸尾和比例；
- 只改变指定视角/表情/动作。

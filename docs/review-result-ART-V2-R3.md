## 3. 视觉不通过项

### 3.1 头发压过身体

当前正面帧中，深蓝色头发占据主要视觉面积，身体只剩很小一块。结果不是“圆润”，而是“头大身小”。

要求：

- 头发总量不超过肩宽 1.35 倍；
- 头发不能遮住围裙主体；
- 围裙和腰部至少保留 2 个清楚色层；
- 身体从颈到脚至少 34 px 可读。

### 3.2 鳍耳不够大

参考图的核心识别点是左右两枚大鲸鳍。当前鳍耳像素太少，缩小后像发饰。

要求：

- 左右鳍耳在 48×72 下仍各有至少 8～12 px 的轮廓；
- 鳍耳从头部两侧伸出，而不是贴在头顶；
- 内层至少 2 个色阶，外侧有清楚尖角。

### 3.3 鲸尾不可读

当前正面看不到明显鲸尾，侧面也不够强。

要求：

- 一侧后方至少保留一个清楚的鲸尾剪影；
- 尾鳍不能和外套或头发混在一起；
- `left` / `right` 至少有明显鲸尾方向差异。

### 3.4 服装层级丢失

当前服装主要有深蓝色块和一条浅色横带，没有参考图里的女仆/学院服层次。

要求：

- 深蓝外层；
- 冰白围裙或胸口层；
- 腰部鲸尾扣；
- 至少保留两个清楚的明暗层。

### 3.5 与 WorkBuddy 母版不一致

WorkBuddy 已锁定的主参考：


当前 R3 结果只保留了“蓝发+鳍耳+深蓝服装”的抽象方向，没有保住母版的：

- 白色围裙主体；

- 圆润可爱的“蓝色大肥鱼”轮廓。
